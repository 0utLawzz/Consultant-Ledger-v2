| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability in Consultant Ledger v2, please report it privately.

**Preferred contact:** net2outlawzz@gmail.com  
**Subject line:** `[SECURITY] Consultant-Ledger-v2`

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive an acknowledgement within a reasonable time. Please do not disclose the issue publicly until it has been addressed.

## Scope

This policy covers the application code in this repository. Third-party dependencies should be reported to their respective maintainers when appropriate.
